# FizzBuzz API

Projet Symfony autour de l'exercice FizzBuzz.

## Stack

* PHP 8.4
* Symfony 8.1

## Installation

```bash
composer install
```

## Lancement

```bash
symfony server:start
```

## Tests

```bash
php bin/phpunit
```
